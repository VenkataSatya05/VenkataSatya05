## Featured Projects

### 🧠 Carnatic Raaga Classification System
**Tech Stack:** Python · PyTorch · HTDemucs · Scikit-learn  
Hybrid CNN-BiLSTM model with attention mechanism classifying 10 Carnatic ragas from vocal performances with **98.76% accuracy**. Engineered a full preprocessing pipeline including source separation, silence removal, augmentation, and pitch-based feature extraction from live concert recordings.

### 🩺 Reneuw — Rewiring Minds, Restoring Lives
**Tech Stack:** FastAPI · Flutter · LangChain · MongoDB Atlas · TensorFlow · Firebase  
mHealth app for post-stroke rehabilitation integrating physical, cognitive, and emotional support. Features a voice/text chatbot powered by Gemini 1.5 and a CNN-based CT scan classifier achieving **95% accuracy**, with a scalable health tracking and meal logging pipeline.

### 🤖 OpenClaw — AI Discord Agent
**Tech Stack:** Python · LangChain · Ollama · Discord API · FastAPI · MongoDB  
AI agent integrated into Discord using local LLMs via Ollama, enabling users to interact with AI capabilities directly from the chat interface. Built as part of my internship at SimplyFI Softech.

### 🗣️ LGBTQIA+ Hate Speech Detection in Dravidian Languages
**Tech Stack:** Python · TensorFlow · Wav2Vec 2.0 · IndicBERT · Hugging Face  
Audio-based BiLSTM with attention achieving **85.71% accuracy** and text-based IndicBERT classifier achieving **88.9% (Telugu) / 87.5% (Malayalam)**. Includes annotated datasets for low-resource language hate speech detection. *Published at SPELLL 2025.*
